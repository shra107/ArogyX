> **Detect medicine overcharging in seconds.**  
> Upload any hospital or pharmacy bill — ArogyX compares every medicine against a database of **2,46,064 real Indian drugs** and instantly flags overcharging with exact percentages and excess amounts.

---

## The Problem

India's NPPA has detected **₹10,013 crore** in pharmaceutical overcharging since inception — yet patients have no fast, automated way to verify their medicine bills. The government's Pharma Sahi Daam app checks one drug at a time. No tool exists for full-bill, AI-powered fraud detection.

**ArogyX solves this.**

---

## Features

| Feature | Detail |
|---|---|
| **Bill Upload** | PDF, JPG/PNG image, camera scan, or manual entry |
| **AI Name Matching** | 4-stage pipeline: exact → fuzzy (rapidfuzz) → NIH RxNorm API → ingredient-level |
| **246K Drug Database** | Indian Medicine Dataset — price, composition, manufacturer, pack size |
| **Per-item Fraud Report** | Overcharge %, severity (Critical/Medium/Low), excess amount charged |
| **Interactive Dashboard** | KPI cards, price comparison charts, filterable table, CSV + HTML export |
| **Multilingual** | English, Hindi (हिन्दी), Marathi (मराठी) |

---

## How It Works

```
Bill (PDF / Image / Manual)
        │
        ▼
   OCR / Parser  ──→  [medicine name, qty, billed price]
        │
        ▼
   4-Stage Matching
   ┌─ 1. Exact match  (name cleaned & looked up in SQLite)
   ├─ 2. Fuzzy match  (rapidfuzz token_set_ratio ≥ 75)
   ├─ 3. RxNorm API   (brand → generic via NIH, free)
   └─ 4. Ingredient   (active ingredient search in compositions)
        │
        ▼
   Per-unit Price Comparison
   (pack size normalised: "strip of 10 tablets" → price ÷ 10)
        │
        ▼
   Fraud Report  →  overcharge %, severity, excess amount
```

## Quick Start

### 1. Clone the repo
```bash
git clone https://github.com/shra107/ArogyX.git
cd ArogyX
```

### 2. Install dependencies
```bash
pip install -r requirements.txt
```

> **Tesseract OCR** is also required for image/camera scanning:
> - Windows: download from https://github.com/UB-Mannheim/tesseract/wiki
> - Ubuntu: `sudo apt install tesseract-ocr`
> - macOS: `brew install tesseract`

### 3. Download the medicine database (~30 MB, run once)
```bash
python download_data.py
```

### 4. Run the app
```bash
streamlit run app.py
```

Open **http://localhost:8501** in your browser.

## Project Structure

```
ArogyX/
├── app.py               # Streamlit UI — interactive dashboard
├── backend.py           # OCR, PDF parsing, fraud detection entry point
├── price_lookup.py      # Core engine: DB bootstrap, fuzzy matching, overcharge calc
├── download_data.py     # One-time setup: downloads medicine CSV + builds SQLite DB
├── init_db.py           # Legacy DB initialiser (small mrp_master reference)
├── requirements.txt     # Python dependencies
├── .streamlit/
│   └── config.toml      # Streamlit server config
└── data/
    └── sample_bill.csv  # Sample bill for demo
```

> `data/indian_medicine_data.csv` and `fraud_detection.db` are **not in the repo** — they are generated by `download_data.py` at setup time (too large to commit).

## Tech Stack

| Layer | Technology |
|---|---|
| UI | Streamlit |
| OCR | Tesseract (pytesseract) + pdfplumber |
| Fuzzy Matching | rapidfuzz |
| Drug Name API | NIH RxNorm REST API (free, no key needed) |

| Local DB | SQLite (auto-built from CSV) |
| Charts | Plotly |
| Language | Python 3.11 |

## Data Sources

- **Medicine prices & names:** [Indian Medicine Dataset](https://github.com/junioralive/Indian-Medicine-Dataset) — 2,46,064 active Indian medicines with price, composition, manufacturer, pack size
- **Drug name normalisation:** [NIH RxNorm API](https://rxnav.nlm.nih.gov) — free, no API key required

## Overcharge Severity Thresholds

| Severity | Overcharge |
|---|---|
| 🔴 Critical | > 50% above MRP |
| 🟠 Medium | 20–50% above MRP |
| 🟡 Low | 5–20% above MRP |
| 🟢 Negligible | < 5% above MRP |
